# Contributing to dev-universe

Thank you for helping make this better! 🙌

## Rules

1. **Only add repos that are actively maintained** (last commit within 1 year)
2. **Minimum 500 GitHub stars** (exceptions for hidden gems — justify it)
3. **No duplicates** — search before adding
4. **Add to the correct category file**
5. **Follow the table format exactly**

## Table Format

```markdown
| [Repo Name](link) | Short description | ![Stars](https://img.shields.io/github/stars/owner/repo?style=flat-square) |
```

## Steps

1. Fork this repo
2. Add your entry in the correct `.md` file
3. Keep alphabetical order within sections
4. Submit a Pull Request with title: `Add: repo-name to category/file`

## What NOT to add

- Dead or unmaintained repos
- Paid tools (unless they have a meaningful free tier)
- Your own repo unless it's genuinely popular and useful
- Duplicate entries

---

Quality over quantity. Always.
